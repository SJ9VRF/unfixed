# Controlled Synthetic User Profiles

This frozen sample contains 120 synthetic user profiles generated by the same profile generator used by the research benchmark. It is intentionally synthetic: no real user data, personal data, temporal metadata, or external records are included.

Each profile contains seven preference dimensions drawn from the benchmark preference space, optional context-specific overrides, confidence, evidence count, stability, and a communication-style attribute. The sample is provided for inspection, demo reproduction, and schema testing; headline benchmark metrics are produced by the evaluation runners, not by this sample alone.

## Files

- `synthetic_profiles.jsonl` — frozen, date-free profile sample.
- `../docs/benchmark-spec.md` — benchmark axes and required metrics.
- `../results/` — generated benchmark outputs.

## Scope

This dataset is a mechanism-research artifact. It does not represent a real population and must not be used to claim real-world user satisfaction, trust, fairness, or demographic performance.
