# Privacy and data handling

The released benchmark uses synthetic users. It contains no intentionally collected personal human data. The human-evaluation package stores only study labels supplied by participants; a production study should use informed consent, data minimization, access controls and a retention/deletion policy approved by the study owner.

The code includes secret-like value redaction and rejects sensitive metadata keys during validation. These safeguards are defense-in-depth for the research artifact, not a claim of production privacy compliance.
