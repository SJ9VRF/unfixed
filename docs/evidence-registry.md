# Evidence Registry

This is the machine-readable provenance index behind the Evidence Layer. It links each documented experiment to the code that runs it, frozen configuration (when present), raw outputs, and SHA-256 hashes. The registry is generated by `python scripts/build_evidence_registry.py`; it is not hand-maintained.

## Provenance contract

- Every experiment ID in the journal must appear here exactly once.
- Every referenced code/config/raw-evidence path must exist.
- Every stored SHA-256 must match the current file bytes.
- Homepage experiment/failure/decision counts must match the registry and evidence documents.
- Reproduction writes to `scratch/` by default so frozen `results/` are not silently overwritten.
- Historical Git commits are not reconstructed.
- External benchmark or human-study results are absent until actually executed.
